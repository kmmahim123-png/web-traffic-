An advanced, independent, and high-precision Website Traffic Checker and Domain Authority platform created by **km.mahim**. Check monthly organic visits, Domain Rating (DR), top search keywords, and competitor traffic for free without registration.

---

## 🚀 Key Features

* **Real-World Value Matching:**
  - Evaluates live web footprints and SERP ranking signals.
  - Correctly reports **0 visits / $0 value** for unranked staging apps, preview URLs (e.g. `*.vercel.app`, `*.netlify.app`), or personal staging sites with no organic search footprint.
  - Accurately models multi-million monthly visit numbers for verified global sites (e.g. `ahrefs.com`, `coca-cola.com`, `apple.com`, `github.com`).
* **Original km.mahim Branding:**
  - Custom geometric monogram SVG logo and dark electric cyan & sapphire color palette (`#00D2FF`, `#3A7BD5`).
  - Completely original UI, eliminating any trademark or copyright infringement concerns.
* **Domain Rating (DR) & URL Rating (UR):**
  - Conic gradient visual gauges displaying log-scale authority ratings (0-100).
* **Interactive Organic Traffic Trend:**
  - Chart.js interactive curve with time range toggles (1 Year, 6 Months, All Time) and monthly visit tooltips.
* **Top Countries Distribution:**
  - Regional traffic share breakdown with country flags and percentage progress bars.
* **Top Organic Search Keywords:**
  - Real search terms with Gold/Silver/Bronze SERP position badges, monthly search volume, and traffic driven.
* **Top Organic Pages:**
  - URL list with outbound navigation and traffic share percentages.
* **Competitor Comparison:**
  - Multi-target side-by-side comparison with instant diff tables.
* **Batch Traffic Checker:**
  - Bulk analyze up to 25 domains simultaneously with CSV export.
* **Export Utilities:**
  - One-click export to CSV and JSON formats.

---

## 🛠️ Technology Stack

- **Backend:** Node.js, Express.js, native DNS resolution, HTTPS client
- **Frontend:** HTML5, Tailwind CSS, Chart.js, Lucide Icons, Vanilla JavaScript SPA
- **Testing:** Automated integration test runner (`npm test`)

---

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Tests
```bash
npm test
```

### 3. Start the Server
```bash
npm start
```

Visit the application at: **`http://localhost:3000`**
